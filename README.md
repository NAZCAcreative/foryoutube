# 컷룸

휴대폰 촬영본이나 온라인 수업을 올리면 이 PC에서 가로 본편, 화면 전체를 담은 쇼츠, 세로 화면을 꽉 채운 크롭 쇼츠를 자동으로 만듭니다.

## 실행

Windows PowerShell에서 프로젝트 폴더를 열고 실행합니다.

```powershell
.\start.ps1
```

브라우저에서 [로컬 스튜디오](http://127.0.0.1:4001)를 엽니다. **예시로 테스트**를 누르면 89초짜리 합성 한국어 수업이 실제 편집 과정을 거칩니다. **영상 선택** 또는 드래그 앤 드롭으로 본인 영상도 시험할 수 있습니다. SRT/VTT가 있다면 먼저 첨부하거나 영상과 함께 놓습니다.

새 PC에는 Python 3.11 이상, FFmpeg와 FFprobe가 필요합니다. FFmpeg는 H.264, AAC, libass와 `scale` 필터의 `reset_sar` 옵션을 지원해야 합니다. Python 의존성은 `python -m pip install -r requirements.txt`로 설치합니다. 포트는 `.\start.ps1 -Port 8766`처럼 바꿀 수 있습니다.

## 편집과 저장

기존 영상은 **장면 자르기 → 자동 추천 비교**를 열면 원본 시각, 추천 이유, 현재 초안에 이미 포함된 추천 구간의 시간 비율이 표시됩니다. 각 장면을 눌러 들어본 뒤 **이 구간을 초안에 적용**을 누르세요. 현재 버전의 컷만 바뀌며 자막 수정과 화면 스타일을 이어서 쓸 수 있습니다. **컷 되돌리기**로 이전 구성을 비교하고 **변경 저장**으로 출력 파일에 반영합니다.

편집 중인 장면·자막·스타일은 본편과 두 쇼츠별로 이 브라우저에 임시 저장됩니다. 새로고침해도 같은 저장본에서 작업을 이어갑니다. **수정 취소**는 현재 버전의 임시 수정을 지웁니다. 두 탭에서 서로 다른 편집을 하면 각 탭의 초안을 따로 보관합니다.

1. **편집할 버전을 고릅니다.** 가로 본편은 50~60분 수업에서 5~10분을 목표로 합니다. 두 쇼츠는 60초 이내입니다. **전체 담기**는 판서와 공유 자료 전체를 흐린 배경 위에 담습니다. **꽉 채우기**는 가로 원본의 비율을 유지하고 좌우를 똑같이 잘라 가운데를 9:16 화면에 채웁니다. 크롭 위치를 옮겼다면 **화면 스타일 → 중앙 맞춤**으로 되돌릴 수 있습니다.
2. **장면 자르기**에서 본편 장면을 고릅니다. **선택 장면 나누기**는 대사 경계, 5초, 10초 중 고른 기준을 적용합니다. **여러 개 선택**으로 원하는 장면을 체크하면 같은 기준으로 한 번에 나눕니다. 대사 경계는 수정한 자막의 시각을 반영하고 서로 겹치는 발화는 함께 둡니다. 자막이 없는 장면은 5초 간격으로 나눕니다. 특정 지점에서 자르려면 파형을 누르거나 **원본 시각**에 `1:23.450` 또는 `83.450`을 입력한 후 **재생 위치에서 분할** 또는 `S`를 누르세요. 조각 옆 **빼기**를 누르면 그 시간의 영상과 소리를 덜어내고, **넣기**를 누르면 다시 포함합니다.
3. **자막 맞추기**에서 대사를 검색합니다. **자막만 숨기기**는 글자를 숨기고, **이 대사 구간을 본편에서 빼기**는 표시된 시각의 영상과 소리를 함께 제외합니다. **반복 대사 찾기**는 45초 안에 같은 문구가 다시 나온 경우 두 구간을 비교해 들을 수 있게 합니다. 추가·수정한 자막은 **음성과 자막 함께 확인**으로 점검하고 **전체 자막 시간 이동**으로 일괄 보정할 수 있습니다.
4. **화면 스타일**에서 자막 글꼴, 영상 필터, 페이드, 강조, 도입 내레이션을 고릅니다. 크롭 쇼츠는 중심 슬라이더로 남길 영역을 정할 수 있습니다. 스타일 미리보기는 실제 출력에 사용하는 글꼴과 필터로 만든 한 장면입니다.
5. 본편 타임라인에서 **이음새 듣기**를 누르면 뺀 구간의 앞뒤를 최대 2초씩 이어서 재생합니다. **첫 30초** 또는 **초안 전체 재생**으로 도입과 대화의 흐름을 확인하세요. 편집 중에는 포함할 원본 구간과 수정한 자막을 재생합니다. 저장 후에는 **첫 30초**와 **저장본 전체 재생**에서 내레이션·필터·전환을 적용한 MP4를 재생합니다. **컷 되돌리기**(`Ctrl/Cmd+Z`)와 **다시 실행**(`Ctrl/Cmd+Shift+Z`)은 컷 편집을 한 단계씩 변경합니다. **변경 저장** 후 MP4와 편집본 기준 SRT를 받을 수 있습니다. 남길 시간과 효과가 같으면 편집 경계만 저장합니다. 본편은 1280×720, 쇼츠는 720×1280이고 세 버전은 각각 저장합니다.

추천은 질문, 설명, 반응이 나오는 구간을 대사 경계와 음량으로 찾습니다. 본편에서는 이미 고른 구간과 표현이 많이 겹치는 설명의 순위를 낮춥니다. 대사 시각상 질문 바로 뒤에 답변이 있고 허용 길이에 들어오면 함께 담습니다. 길이가 모자라면 앞선 문답 끝에 자를 자리를 찾습니다. 동시에 말하는 구간은 무음으로 잘라내지 않습니다. 무음 영상은 화면 변화량을 사용합니다. 원본과 편집본은 `.local/jobs/`에 저장합니다. `CUTROOM_DATA`로 경로를 바꿀 수 있습니다. 작업은 한 번에 하나씩 처리하며 보관함에서 다시 열 수 있습니다.

브라우저가 원본의 영상 형식을 재생할 수 없으면 첫 원본 재생 때 편집용 MP4를 한 번 준비합니다. 이후 같은 작업에서는 그 파일을 재사용하며, 최종 편집본은 업로드한 원본으로 내보냅니다.

## 제작 사례를 편집기에 적용한 근거

- 씨네21 김성훈 기자는 스마트폰으로 촬영한 한 시간 대담을 여러 번 다시 보며 24분 초벌본을 15분으로 줄였습니다. 교육 유튜버 Thomas Frank는 같은 문장을 여러 번 녹음한 뒤 편집할 때 쓸 테이크를 고르는 과정을 설명했습니다. 컷룸에서는 검색한 대사 구간을 바로 덜어내고 반복 발화를 들어본 뒤 선택할 수 있습니다. [씨네21 제작기](https://cine21.com/news/view/?mag_id=89682) · [Thomas Frank 인터뷰](https://www.smartpassiveincome.com/download/Transcript-SPI324.pdf#page=19)
- CHI 2024의 ChunkyEdit 연구는 인터뷰의 주제·문답 단위를 중심으로 정리하는 작업을 전문 편집자 8명과 평가했습니다. 컷룸에서는 추천 장면의 맥락을 먼저 확인하고 골라서 세분화하도록 설계했습니다. [연구 논문](https://www.mackenzieleake.com/projects/chunkyedit/ChunkyEdit_small.pdf)
- YouTube는 실제 게시 영상의 첫 30초 이후 시청자 비율을 인트로 지표로 보여줍니다. 컷룸의 첫 30초 재생은 질문과 도입이 어떻게 이어지는지 게시 전에 검토하는 기능입니다. [YouTube 공식 안내](https://support.google.com/youtube/answer/9314415?hl=ko)

## 이 PC의 음성 기능

로컬 faster-whisper와 캐시된 다국어 모델이 있으면 자막을 자동 생성합니다. CUDA에서 실패하면 CPU로 재시도합니다. 기본 인터프리터, 프로젝트 가상환경, 인접한 vtranscript 가상환경을 순서대로 확인합니다. 다른 환경은 `CUTROOM_WHISPER_PYTHON`에 해당 Python 실행 파일, `CUTROOM_WHISPER_MODEL`에 CTranslate2 모델 폴더를 지정합니다. CPU만 사용할 때는 `CUTROOM_ASR_DEVICE=cpu`를 지정합니다. 모델이 없는 환경에서도 SRT/VTT를 첨부하거나 영상 신호로 편집할 수 있습니다.

도입 내레이션은 Windows에 설치한 한국어 SAPI 음성으로 별도의 도입 장면을 합성합니다. 첫 버전의 장면 추천은 원본의 대사와 장면 신호를 기준으로 합니다. 실제 유행 문구 데이터와 시청 반응을 활용한 추천은 후속 실험 범위입니다.

## 검증

```powershell
python -m unittest discover -s tests -v
node --test tests/test_cut_plan.mjs tests/test_draft_cache.mjs
python -m pip install -r requirements-dev.txt
python -X utf8 -m tools.smoke
```

GPU 전사, Windows 음성 합성, 50분 원본까지 검증하는 명령은 다음과 같습니다.

```powershell
python -X utf8 -m tools.smoke --speech --voice --long
```

검증은 임시 작업 폴더를 사용합니다. 50분 테스트는 제공된 합성 수업을 반복한 영상과 시간에 맞게 이어 붙인 SRT로 길이·렌더링·다운로드를 확인합니다. 무자막 전사는 별도의 업로드로 확인합니다.
